# Contributing to Divine

Thanks for taking the time to help improve Divine.

Divine is currently in active development and the main application source is not published in this repository. For now, the most useful public contributions are high-quality bug reports, feature requests, documentation feedback, and reproducible examples of Studio integration problems.

## Reporting a bug

Before opening a report, check the existing issues to see whether the problem is already known.

A useful bug report includes:

- Divine version/build
- Windows version
- Roblox Studio version when relevant
- What you were trying to do
- What you expected to happen
- What actually happened
- Steps that reproduce the issue
- Relevant Divine or Studio errors

Screenshots and logs are welcome, but remove API keys, tokens, personal paths when sensitive, and private project information before posting.

## Requesting a feature

Tell us about the problem or workflow you want to improve, not only the implementation you have in mind. Examples of how you would use the feature are especially helpful.

## Security issues

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) instead.

## Source contributions

The Divine application is not currently maintained as an open-source project. If that changes, contribution and development setup instructions will be added here.
