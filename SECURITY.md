# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Divine is still in active development, and we want security reports to reach us before technical details are made public. If you believe you have found a vulnerability, contact the project maintainer privately through the contact method listed on the maintainer's GitHub profile.

Please include:

- A clear description of the issue
- The Divine version/build involved
- Steps to reproduce it
- The impact you believe it could have
- Relevant logs or screenshots, with secrets and personal information removed

Do not include API keys, access tokens, credentials, private Roblox project data, or other secrets in a report.

## Scope

Useful reports include issues involving Divine's desktop application, local bridge, Roblox Studio integration, plugin installation/update process, or handling of credentials and local data.

We appreciate responsible reports and ask that vulnerabilities are not publicly disclosed until there has been reasonable time to investigate and address them.
